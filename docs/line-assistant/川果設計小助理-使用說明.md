# 川果設計小助理 使用說明

> 給團隊成員看的操作說明。技術建置細節請看同資料夾的《第一步-LINE串接n8n-建置指南》。

最後更新：2026-08-27

---

## 1. 這個小助理在做什麼

把 LINE 上的對話與檔案，自動整理進公司的 Notion 與 Dropbox，不用再手動翻對話紀錄找報價單、找進度、找誰說過什麼。

一則訊息進來，小助理會自動做這些事：

| 訊息類型 | 自動處理 |
|---|---|
| 文字 | AI 判讀分類、寫 40 字摘要、抓出負責人與到期日 → 存進 Notion 訊息紀錄 |
| 照片 | AI 看圖說明內容、判斷用途（施工照／完工照／設計圖／材料樣品⋯）、辨識圖中文字 → 備份 Dropbox＋建索引 |
| 檔案（PDF／CAD／試算表等） | 依副檔名判斷類型與用途 → 備份 Dropbox、產生分享連結 → 建索引 |
| 有日期時間的事項 | 自動在 Google「川果設計」日曆建立行程 |
| 閒聊、貼圖、「收到」「好的」 | 只留紀錄，不送 AI（省成本） |

---

## 2. 怎麼開始用

### 2-1 把小助理加進群組

在 LINE 群組裡邀請官方帳號 **川果設計小助理（@549mpmon）** 加入即可。

**新群組會自動開始記錄**，不需要任何人核准。小助理會自動在 Notion「02｜群組登錄」建一列，狀態直接是「已登錄」，從第一則訊息就開始歸檔。

### 2-2 不想被記錄的群組怎麼辦

到 Notion「02｜群組登錄」找到該列，把 **「註冊狀態」改成「停用」**，之後這個群組的訊息與檔案就不會再被記錄。

### 2-3 一對一私訊

直接跟小助理的官方帳號對話也會被記錄，在 Notion 裡群組名稱會顯示成「個人：某某」。

## 3. 記錄會出現在哪裡

### Notion

| 資料庫 | 內容 |
|---|---|
| **02｜群組登錄** | 有哪些群組正在被記錄，可在這裡停用或補上專案關聯 |
| **05｜檔案索引** | 所有備份的檔案：檔名、類型、用途分類、Dropbox 連結 |
| **06｜訊息紀錄** | 所有訊息：摘要、分類、優先級、負責人、到期時間、群組名稱 |

06 有兩個好用的檢視：**依群組**（看單一群組的時間軸）、**行事曆**（看有到期日的事項）。

### Dropbox

檔案路徑規則：

```
/NIDDESIGN-LINE助理/{群組名稱}_{群組ID後6碼}/{年-月}/{時間戳}_{發送者}_{原檔名}
```

例：`/NIDDESIGN-LINE助理/文心南六路案_a67df0/2026-08/20260826-145930_Nic Yen_報價單.pdf`

Notion 的檔案索引裡有可直接點開的分享連結，不用自己去 Dropbox 翻。

### Google 行事曆

訊息裡有明確日期時間時（例如「8/28 下午三點丈量」「9/4 前要出圖」），會自動在 **「川果設計」日曆** 建立事件：

- **標題**＝AI 整理的摘要
- **說明**＝來源群組／發送者／負責人／原始訊息
- **時長**＝預設 1 小時

## 4. AI 分類的六種類別

| 分類 | 什麼樣的訊息 |
|---|---|
| 工作事項 | 要有人去做的事：出圖、叫料、修改、進場、驗收 |
| 聯絡事項 | 要聯繫某人或廠商、交換聯絡方式 |
| 行事曆 | 有明確日期的會議、丈量、進場、驗收 |
| 決策 | 已拍板的選擇：選定材料、確認尺寸、同意變更 |
| 報價金額 | 涉及價格、追加減帳、請款、付款 |
| 一般資訊 | 閒聊、回覆確認、無後續動作 |

分類為「一般資訊」的自動標記為已處理，其他的標成「待處理」等你確認。

## 5. 使用上的小提醒

**傳照片 vs 傳檔案**
LINE 的「照片」傳送方式會壓縮畫質。要保留原始檔（尤其是 DWG 圖檔、報價單 PDF），請用 **「檔案」** 方式傳送。

**檔名越清楚越好**
檔名含「報價」「合約」「平面圖」「完工」等關鍵字時，小助理能自動歸到正確的用途分類，省下人工整理。

**日期講清楚**
「下週三下午兩點」「9/4 前」這類寫法 AI 都能推算；但「改天再約」就不會產生行事曆事件。

**個資提醒**
群組對話會被長期保存。不宜留存的內容請避免在有小助理的群組發送；業主群建議先評估是否納入。

## 6. 遇到問題

| 狀況 | 可能原因與處理 |
|---|---|
| 訊息沒被記錄 | 檢查 Notion 02 該群組的「註冊狀態」是不是被設成「停用」 |
| 發送者顯示成一串英數字 | 該成員未同意 LINE 提供個人資料，屬正常情形 |
| 大檔案沒備份成功 | 單檔上限 150MB，超過會在 05 標成「上傳失敗」 |
| 分類明顯判錯 | 直接在 Notion 改欄位即可；若常態性判錯，回報以便調整提示詞 |
| 小助理自己發的訊息 | 不會被記錄（LINE 不會對官方帳號自己發的訊息送出通知） |

## 7. 系統組成

```
LINE 官方帳號  →  自動化流程（Railway 雲端）  →  ┬→ Notion（訊息／檔案索引）
                                              ├→ Dropbox（檔案備份）
                                              └→ Google 行事曆（到期事項）
```

- AI 文字分類：Claude Opus
- AI 影像分析：Claude Haiku
- 錯誤發生時會自動透過 LINE 通知管理者
